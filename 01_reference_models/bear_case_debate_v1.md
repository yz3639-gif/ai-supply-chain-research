# Bear Case Debate v1

日期：2026-05-25  
用途：严肃记录反方论证和可证伪指标。  
说明：这是研究框架，不是个人投资建议。

## 光通信不是主瓶颈

反方理由：铜互连和架构优化可延缓光通信需求；订单可能提前拉货；Broadcom/Marvell 可能压缩第三方空间。  
可证伪指标：SMTC/MTSI/MXL/VECO 指引连续两季上修，1.6T/3.2T 订单扩大，毛利不因竞争明显下滑。  
降级触发：光通信公司连续两季 guide inline/miss，或增长被解释为一次性拉货。

## 电力散热被效率提升抵消

反方理由：GPU 效率提升降低每 token 电力需求，backlog 不等于收入，竞争压毛利。  
可证伪指标：POWL/MOD/AAON/FIX backlog 继续增长且 GM 稳定。  
降级触发：book-to-bill <1，GM 连续两季低于阈值且为结构性。

## AP/HBM 已提前透支

反方理由：HBM 和先进封装投资已被市场定价，probe/inspection 订单 lumpy，客户集中。  
可证伪指标：FORM/ONTO/CAMT guide 上修，Dragonfly G5/HBM/probe 订单连续出现。  
降级触发：订单一次性，毛利或现金流恶化。

## 冷门材料路线商业化失败

反方理由：POET/LWLG/ALMU 技术路线过早，qualification 周期拉长，融资摊薄。  
可证伪指标：POET late-2026 samples，LWLG foundry transfer，ALMU 商业订单。  
降级触发：里程碑推迟两个周期，融资或现金 runway 恶化。

## 中国竞争压低利润率

反方理由：设备、材料、光模块链可能被中国供应商价格竞争压低；ACMR/AXTI/CAMT 存在地缘和区域集中风险。  
可证伪指标：毛利稳定，非中国客户订单重复，出口/许可/Tongmei 风险缓和。  
降级触发：毛利连续下滑，中国/出口限制影响收入确认。
