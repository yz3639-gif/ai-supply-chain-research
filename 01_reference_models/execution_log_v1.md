# Execution Log v1

日期：2026-05-25  
用途：记录少量、可持续填写的预测和复盘。  
说明：这是研究框架，不是个人投资建议。

## v3.2 状态修正

旧的六段式复杂日志降级为历史模板。默认使用 `decision_journal_simple_v1.md` 的简单格式。

原因：如果一个日志系统复杂到不会持续填写，它不会提高决策质量，只会制造控制感。

## 最小格式

每条记录只需回答：

1. 我当时怎么想？
2. 什么事实会证明我错？
3. 事件后发生了什么？
4. 我做了什么决定，为什么？
5. 30-90 天后错在哪？

## [2026-05-24/25] SMTC / Q1 FY2027 pre-event

**我当时怎么想**

- Thesis：Semtech 可能受益于 800G/1.6T/3.2T optical/copper interconnect 升级。
- 为什么现在值得关注：公司已公开给出 Q1 FY2027 guide，并强调 AI data-center networking 与下一代 optical/copper interconnect。
- 什么事实会证明我错：结果低于公司 guide；下一季 outlook 不增强；Signal Integrity/1.6T/3.2T 没有新证据；毛利或 FCF 出现结构性恶化。

**事件后发生了什么**

- 结果是否 beat：待 2026-05-26 盘后填写。
- Outlook 是否 raise：待填写。
- Thesis 是否有新证据：待填写。
- Margin/FCF 是否健康：待填写。
- 组合风险是否允许：待填写。

**决定**

- 动作：待填写。
- 一句话理由：待填写。
- 如果 30-90 天后错了，最可能错在哪：hidden demand 不可见、产品 mix 不可见、估值提前反映、同主题相关性过高。
