## 使用原则

1. 默认从 `00_active_system/` 开始，不再从旧 v1/v2 报告做决策。
2. `01_reference_models/` 只作研究辅助，不直接触发交易。
3. 每个新事件先写入 `prospective_event_ledger_v1.csv`，再做事后复盘。
4. 旧文件保留在 `99_archive_superseded/`，需要时可以恢复。
